# Written in Chalk: DSA Patterns notebooks

The code from the DSA Patterns videos, one notebook per problem. Each one states the problem, then works
through every solution from the brute force up, with examples you can change and run again. The last section
lists similar problems to try on your own.

like. To run one locally, use Python 3 and Jupyter. The notebooks use only the standard library.
